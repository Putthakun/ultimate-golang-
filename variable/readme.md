# Variable ใน Go

## 1. Built-in Types (Type พื้นฐาน)

Type พื้นฐาน เช่น `int`, `uint`, `bool`, `string` บอกข้อมูล 2 อย่าง:

1. ใช้หน่วยความจำกี่ **byte**
2. หน่วยความจำนั้นแทนข้อมูลชนิดอะไร

### Type ที่ระบุขนาดชัดเจน

| Type    | ความหมาย                         | ขนาด            |
| ------- | -------------------------------- | --------------- |
| `uint8` | จำนวนเต็มไม่ติดลบ (0 ขึ้นไป)          | 1 byte (8 bit)  |
| `int32` | จำนวนเต็มทั้งลบและบวก                | 4 byte (32 bit) |

### Type ที่ขนาดไม่ตายตัว

`int` / `uint` มีขนาดตามเครื่อง (32 หรือ 64 bit) ช่วงค่าที่เก็บได้จึงต่างกันไปตามเครื่อง

> **จำไว้:** 1 byte = 8 bit

## 2. Word Size

**Word** คือขนาดข้อมูลมาตรฐานที่ CPU ประมวลผลได้ในครั้งเดียว

| สถาปัตยกรรม | Word size        | ความหมาย                   |
| ----------- | ---------------- | -------------------------- |
| 32-bit      | 4 byte (32 bit)  | CPU จัดการข้อมูลทีละ 32 bit |
| 64-bit      | 8 byte (64 bit)  | CPU จัดการข้อมูลทีละ 64 bit |

## 3. Zero Value (ค่าเริ่มต้น)

ตัวแปรที่ประกาศแต่ไม่ได้กำหนดค่า จะได้ค่าเริ่มต้นตามชนิดข้อมูลนั้น

| ชนิด    | Zero Value  |
| ------- | ----------- |
| Boolean | `false`     |
| Integer | `0`         |
| Float   | `0`         |
| Complex | `0i`        |
| String  | `""` (ว่าง)  |
| Pointer | `nil`       |

## 4. การประกาศตัวแปร

### แบบใช้ `var` (ได้ zero value)

```go
var name type
```

```go
var a int     // 0
var b string  // ""
var c float64 // 0
var d bool    // false
```

### แบบสั้น `:=` (Short Variable Declaration)

```go
name := value
```

```go
aa := 10      // int
bb := "hello" // string
cc := 3.14159 // float64
dd := true    // bool
```

Go อนุมาน type ให้เองจากค่าที่กำหนด

## สรุป: ใช้แบบไหนเมื่อไร

| ต้องการ                     | ใช้   |
| -------------------------- | ----- |
| ประกาศโดยใช้ zero value      | `var` |
| ประกาศพร้อมกำหนดค่า          | `:=`  |
